# Образовательная платформа — v6.1

Статический MVP образовательной платформы для дистанционной подготовки школьников 1–9 классов по спортивному программированию.

## Что реализовано

### Ученик
- вход по логину и паролю;
- регистрация ученической учётной записи;
- только опубликованные и назначенные курсы;
- карта курса, следующий шаг и прогресс;
- автоматическая проверка контрольных вопросов и числовых ответов;
- ручная сдача ссылкой/кодом с сохранением фактического содержимого;
- встроенные вопросы куратору с ответом в том же шаге;
- динамический расчёт демонстрационных баллов рейтинга.

### Куратор
- очередь ручной проверки;
- просмотр фактической сдачи ученика;
- принятие или возврат с комментарием;
- список учеников и рассчитываемые сигналы «В графике / Замедлился / Выпадает / ЖДЁТ»;
- ответы на вопросы учеников.

### Администратор
- создание курса;
- редактирование паспорта курса;
- создание/редактирование/удаление модулей;
- создание/редактирование/удаление шагов;
- выбор типа шага из библиотеки;
- добавление пользовательского типа шага;
- публикация/снятие публикации;
- полное удаление курса вместе с зависимыми назначениями, вопросами, отзывами и работами;
- создание, редактирование и удаление назначений «ученик → курс → куратор».

## Учебное содержание
- 3 курса;
- 9 модулей;
- 30 шагов: Scratch — 10, Minecraft Education — 8, Python — 12;
- типы: Теория, Контрольный вопрос, Scratch, Проект, Minecraft Education, Задача с тестами.

В данных исправлена ошибка демонстрационной записи `r1`: проект `2.3.1 «Проект: мост через реку»` относится к Minecraft Education, а не к Python.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Демо-учётные записи
- Ученик: `masha / 1234`
- Куратор: `curator / 1234`
- Администратор: `admin / 1234`

Новая регистрация создаёт ученика без курсов; курс появляется после назначения администратором и только после публикации.

## Автопроверка Python

Так как это статический браузерный MVP без серверного sandbox, произвольный Python-код не выполняется напрямую. Для шести встроенных задач Python реализована демонстрационная проверка структуры решения и условий задачи. Для production необходимо вынести запуск пользовательского кода в изолированный серверный sandbox с лимитами CPU/RAM/времени и отдельной БД.

## Хранение данных

Все изменения сохраняются в `localStorage`. Для полного сброса данных удалите ключ:

```js
localStorage.removeItem("edu-platform-final-v6");
location.reload();
```

## Визуальная система

Использованы значения брендбука: Onest, JetBrains Mono для кода/чисел, фирменная палитра и статусы с иконками. Декоративный градиент с экрана входа удалён.
