# Образовательная платформа — финальный demo stand v5

Фронтенд демо-стенда для кейса «Образовательная платформа» ФСП Чувашии. Версия v5 дополнена API-ready mock backend по предоставленному контракту `/api`.

## Запуск

Требуется Node.js 18+.

```bash
npm start
```

Откройте `http://localhost:8080`.

Если нужен только статический просмотр, `index.html` можно открыть через Live Server.

## Демо-аккаунты

- `student / student`
- `curator / curator`
- `admin / admin`

API login также принимает `student / demo123`, `curator / demo123`, `admin / demo123`.

## Что реализовано

- три роли: ученик, куратор, администратор;
- кабинет ученика с постоянно видимым следующим шагом;
- карта курса `курс → модули → шаги`;
- 3 курса и учебное содержание из предоставленного базового пакета;
- автоматические контрольные ответы и демонстрационный контур Python-проверки;
- ручная очередь куратора, принятие/возврат с комментарием;
- повторная отправка возвращённой работы возвращает её в очередь;
- история выполненных заданий и обратная связь;
- объяснимый рейтинг;
- вопросы ученика/обратная связь;
- конструктор курса: паспорт, добавление модулей, добавление и удаление шагов;
- назначения «ученик ↔ курс ↔ куратор»;
- справочник расширяемых типов шагов;
- API mock backend с `/api/auth`, `/api/catalog`, `/api/courses`, `/api/me`, `/api/steps`, `/api/curator`, `/api/admin` и `/api/health`.

## API

Контракт `/api` основан на предоставленной спецификации: Bearer-токены, роли `student`, `curator`, `admin`, JSON, ISO 8601 и единый формат ошибок.

`server.js` — локальный демонстрационный backend. Он не является production-безопасным sandbox для запуска произвольного пользовательского кода: Python запускается отдельным процессом с тайм-аутом. Для реального продукта нужен изолированный контейнер/песочница.

## Данные

Используются только синтетические демонстрационные данные. Эталонные решения и критерии не выводятся в ученический интерфейс.
