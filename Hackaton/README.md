# Образовательная платформа — финальный MVP стенда

Веб-платформа для дистанционного обучения школьников 1–9 классов спортивному программированию.

## Что реализовано по кейсу

### Три обязательные роли
- **Ученик:** личный кабинет, доступные курсы, положение внутри курса, всегда видимый следующий шаг, история статусов, прогресс, объяснимый рейтинг и обратная связь.
- **Куратор:** закреплённые ученики, очередь ручной проверки, принятие/возврат с комментарием, сигналы «В графике / Замедлился / Выпадает», ответы на вопросы по конкретному шагу.
- **Администратор:** создание курса, паспорт курса, публикация/снятие публикации, просмотр состава «курс → модуль → шаг», назначения, библиотека типов шагов.

### Учебное содержание
Данные перенесены из базового пакета организатора:
- 3 курса;
- 9 модулей;
- 30 шагов: Scratch — 10, Minecraft Education — 8, Python — 12;
- типы: Теория, Контрольный вопрос, Scratch, Проект, Minecraft Education, Задача с тестами;
- критерии ручной проверки и служебные эталонные материалы отделены от ученического текста.

### Архитектура
Тип шага хранится как данные и отображается через единый компонент. Новый тип добавляется в конфигурацию, а не требует переписывания карты курса.

### Визуальная система
Использованы значения брендбука: Onest, JetBrains Mono для кода/чисел, #3457F0, #F07A2A, #0B1220, #0F172A, #EAF0FE, #E1E6F0, #F4F6FB и статусы с иконками.

## Запуск

### Вариант 1 — статический стенд
Откройте `index.html` через Live Server в VS Code.

### Вариант 2 — простой локальный HTTP
```bash
python -m http.server 8080
```
Откройте `http://localhost:8080`.

## Демо
На экране входа доступны все три роли. Данные синтетические и сохраняются в `localStorage`.

Сброс:
```js
localStorage.removeItem("edu-platform-final-v4");
location.reload();
```

## Что является демо-реализацией
Стенд показывает полный пользовательский контур и состояние данных в браузере. Реальный production backend, серверная БД, авторизация и промышленный sandbox для запуска Python-кода не входят в статический MVP.
